MALWARE THREATS: WORMS, VIRUSES AND TROJANS – CASE STUDY 
 
AIM 
To study and understand the different types of malware threats — Viruses, Worms and Trojans — including their 
definitions, types, propagation mechanisms, real-world examples, and the tools used for detection and prevention. 
 
1. COMPUTER VIRUS 
A computer virus isaself-replicating malicious code that attaches itself to a legitimate host file. It executes when the 
infected file is opened, corrupting data or delivering a destructive payload. Viruses require user interaction to 
spread. 
Types of Viruses: 
 
Type Description 
Boot Sector Virus Infects the Master Boot Record; loads before the OS. 
File Infector Virus Attaches to .exe files; activates on execution. 
Macro Virus Embedded in Office document macros. Example: Melissa (1999). 
Polymorphic Virus Changes its signature each infection to evade antivirus. 
Multipartite Virus Attacks both boot sector and executable files simultaneously. 
Case Study – ILOVEYOU Virus (2000): 
Spread via email with subject 'ILOVEYOU' and a .vbs attachment. It overwrote files and mailed itself to all Outlook 
contacts, infecting over 50 million computers and causing approximately USD 10 billion in damages. 
 
2. COMPUTER WORM 
A computer wormis standalone malware that self-replicates and spreads across networks without needing a host 
file or user interaction. It exploits OS or network vulnerabilities, consuming bandwidth and system resources. 
Types of Worms: 
 
Type Description 
Internet Worm Exploits internet-facing service vulnerabilities. Example: Code Red. 
Email Worm Spreads through email attachments/links. Example: Mydoom. 
Network Worm Uses SMB/FTP protocols to propagate. Example: WannaCry. 
File-Sharing Worm Hides in P2P shared folders to infect downloads. 
Case Study – WannaCry Worm (2017): 
Exploited the EternalBlue vulnerability (MS17-010) in Windows SMB. Spread without any user interaction, encrypting 
files and demanding Bitcoin ransom. Infected over 200,000 systems in 150 countries, severely affecting the UK NHS 
and FedEx. 
Roll No: 2127220801056 Pg no:  
 
3. TROJAN HORSE 
A Trojan horse is malware disguised as legitimate software. Unlike viruses or worms, Trojans do not self
replicate. They rely on social engineering to trick users into installing them, then create backdoors, steal data, or 
download more malware. 
Types of Trojans: 
 
Type Description 
Remote Access Trojan Gives attacker full remote control. Example: DarkComet. 
Banking Trojan Steals online banking credentials. Example: Zeus, Emotet. 
Rootkit Trojan Hides malware at OS or kernel level to avoid detection. 
Downloader Trojan Downloads and installs additional malware silently. 
Case Study – Zeus Banking Trojan: 
Spread via phishing emails, it hooked into browsers to intercept online banking sessions (Man-in-the- 
Browser attack). Infected over 3.6 million computers in the USA alone, stealing hundreds of millions of dollars.
